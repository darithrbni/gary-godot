# 🎮 Projek Game Platformer Simpel GARY

Selamat datang, para anggota GARY! Repositori ini berisi projek starter Godot yang bisa langsung kalian download dan pelajari. Projek ini merupakan checkpoint dari Weekly Meet #2, yang bisa kalian coba teruskan sesuka kalian. Ikuti panduan di bawah ini sesuai dengan kebutuhan kalian:
- **Bagian 1:** Jika kalian hanya ingin membuka dan menjalankan Projek Godot di komputer kalian.
- **Bagian 2:** Jika kalian ingin melanjutkan projek dan mengumpulkan progresnya untuk di-*review*.

---

## 📦 Bagian 1: Cara Download & Membuka Projek di Godot

Kalian tidak perlu mengerti GitHub atau *coding* untuk mulai mencoba Projek ini. Ikuti langkah-langkah berikut:

### 1. Download File Projek (ZIP)
1. Klik tombol hijau bertuliskan **`<> Code`**.
2. Pada menu yang muncul, klik **`Download ZIP`**.
3. Tunggu hingga file `.zip` selesai terunduh ke folder *Downloads* di komputer kalian.

### 2. Import Langsung ke Godot Engine
Godot bisa langsung membaca file `.zip` tanpa perlu kalian ekstrak secara manual terlebih dahulu:
1. Buka aplikasi **Godot Engine** di komputer kalian.
2. Klik tombol **`Import`** di bagian kiri atas.
3. Klik **`Browse`**, lalu cari dan pilih file `.zip` yang baru saja kalian download.
4. Klik **`Open`**.
5. Pilih folder kosong di komputer kalian sebagai tempat mengekstrak dan menyimpan Projek ini (disarankan membuat folder baru), lalu klik **`Select Current Folder`**.
6. Klik tombol **`Import & Edit`**. Projek akan otomatis terbuka di dalam editor Godot!

---

## 🚀 Bagian 2: Cara Mengumpulkan Progres (Fork & Submit)

Jika kalian ingin melanjutkan projek ini dan mengirimkannya agar bisa di-*review* oleh kakak-kakak dari GARY, ikuti alur kerja berikut. **Pastikan kalian sudah memiliki akun GitHub dan sudah *login*.**

### Tahap A: Membuat Salinan Projek Milik Kalian Sendiri (Fork)
Karena kalian tidak bisa mengubah Projek utama secara langsung, kalian perlu membuat salinannya ke akun GitHub kalian sendiri:
1. Di pojok kanan atas halaman repositori ini, klik tombol **`Fork`**.
2. Pada halaman *Create a new fork*, biarkan semua pengaturan apa adanya, lalu klik tombol hijau **`Create fork`**.
3. Sekarang kalian sudah berada di halaman Projek salinan milik kalian sendiri (perhatikan nama akun kalian muncul di pojok kiri atas sebelum nama Projek).

### Tahap B: Mengunduh dan Mengerjakan Progres di Komputer
Agar proses pengumpulan progres lebih mudah, gunakan aplikasi **GitHub Desktop**:
1. Unduh dan pasang [GitHub Desktop](https://desktop.github.com/), lalu *login* menggunakan akun GitHub kalian.
2. Di halaman GitHub **hasil Fork milik kalian**, klik tombol hijau **`<> Code`** > pilih **`Open with GitHub Desktop`**.
3. Pilih lokasi penyimpanan di komputer kalian, lalu klik **`Clone`**.
4. Buka **Godot Engine** > klik **`Import`** > pilih file `project.godot` yang ada di dalam folder hasil *Clone* tersebut > klik **`Import & Edit`**.
5. Silakan lanjutkan projek Game Platformer Simpel kalian di Godot, dan pastikan selalu menekan **`Ctrl + S`** (*Save*) setiap selesai mengedit.

### Tahap C: Menyimpan Perubahan ke GitHub Milik Kalian (Commit & Push)
Setiap kali selesai mengerjakan progres di Godot:
1. Buka kembali aplikasi **GitHub Desktop**. Semua file yang kalian ubah di Godot akan otomatis tercatat di panel sebelah kiri.
2. Di pojok kiri bawah, isi kolom **Summary** dengan deskripsi singkat progres kalian (contoh: `Menambahkan gerakan lompat karakter`).
3. Klik tombol biru **`Commit to main`**.
4. Klik tombol **`Push origin`** di bagian atas layar agar perubahan kalian tersimpan secara online di akun GitHub kalian.

### Tahap D: Mengirimkan Hasil untuk Di-review (Pull Request)
Setelah progres kalian di-*push* ke akun GitHub milik kalian, kirimkan laporan progres tersebut agar bisa di-*review*:
1. Buka halaman GitHub **hasil Fork milik kalian** melalui browser.
2. Klik tab **`Pull requests`** di bagian atas, lalu klik tombol hijau **`New pull request`**.
3. Pastikan arah panah menunjukkan dari repositori *fork* milik kalian menuju repositori utama ini, lalu klik tombol hijau **`Create pull request`**.
4. Tulis nama lengkap kalian dan catatan singkat mengenai apa saja yang sudah kalian kerjakan, lalu klik **`Create pull request`**.
5. Selesai!
